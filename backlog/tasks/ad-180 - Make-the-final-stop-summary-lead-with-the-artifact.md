## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Per AD-369's ruling: once a review loop has stopped, the stop summary leads with the artifact (what changed and where to read it) and puts the per-wave findings after it as a record, so the findings do not frame the developer's one read of the finished artifact. During the loop, questions lead with the finding and only the context needed to answer it. AD-199 writes this into this repo's AGENTS.md as an interim rule; this task carries it into the shipped process guidance once AD-372 decides where that lives. Evidence: a crossover study found students who started with an assistant improved about half as much.

**Why it matters:** Protects the developer's independent read of each finished artifact.

**Why an agent:** guidance text once AD-372 rules
