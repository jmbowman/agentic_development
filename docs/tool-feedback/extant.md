# extant feedback

[extant](https://github.com/scooter-sensei/extant) is the adopted citation drift check in [the federated knowledge note](../prior-art/2026-11-06-federated-knowledge-and-work-items.md). Not yet raised upstream.

## Open items

### 1. Checked documents must be listed one by one

- **Where:** in the package at `plugin/skills/extant/payload/`: `extant/config.py:102-104`, `extant/cli.py:640-713` at 7999ce2.
- **What:** `--verify` checks only the documents named in `.extant.toml` (`primary_doc`, default `NEXT_SESSION.md`, plus `extra_docs`). A knowledge base with dozens of pages needs every page listed, and a new page is silently unchecked until someone adds it.
- **Globs:** not accepted, *verified in source* at 7999ce2, which was still upstream HEAD on 2026-11-26. Config loading only normalises each entry's spelling (`extant/config.py:896`, `normalise_document` at `extant/config.py:591-619`), and `--verify` reads each entry as one path (`extant/gate.py:613-626`), so `docs/**/*.md` would be reported as a `missing-document` finding. The README says so too: "`extra_docs` is a literal list" (`README.md:411`). The nearest existing feature is the installer's `--wide-docs` flag (`plugin/skills/extant/install.py:608-645`, `1108-1112`; the enumeration is `find_wide_documents`, `plugin/skills/extant/detect.py:413-433`). It enumerates tracked documents at the root and under `docs/` once, at install time, and writes each one into `extra_docs`, so a page added later is still unchecked until someone adds it to the list. `--sweep` also surveys documents that aren't listed, but findings in those don't affect the exit code (`extant/sweep.py:681-684`, `extant/sweep.py:772-794`).
- **Suggested fix:** accept glob patterns in `extra_docs` (for example, `docs/**/*.md`), matched against tracked files with the same gitignore-shaped syntax `exclude_paths` already uses (`extant/config.py:263-267`). The matching applies wherever `extra_docs` is read as a list of names: `--verify` (`extant/gate.py:613`), the sweep's split into listed and unlisted documents (`extant/sweep.py:790-794`) and the exclude-conflict check (`extant/sweep.py:760-763`), so a page a glob matches is gated in `--sweep` too. Today extant refuses an exclude that names a document `extra_docs` also names (`README.md:1026`), so `exclude_paths` would need to narrow a glob's matches rather than conflict with them.
